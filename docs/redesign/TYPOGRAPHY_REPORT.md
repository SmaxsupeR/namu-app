# Namu UX v2 — типографика учебных экранов

Ветка: `redesign/ux-v2`. Задача: хангыль — главный визуальный акцент каждого задания.

**Учебная логика, FSRS и проверка ответов не менялись.** Изменены только стили и раскладка.

## 1. Шкала (токены в `src/ui/theme.ts`, описание — в DESIGN.md → Typography → Study type)

| Токен | Что | Размер, sp | Начертание |
|---|---|---|---|
| `koreanPrompt` / `KoreanHero` | главное корейское слово | 56 (до 4 слогов) → 50 → 44 → 40 → 36; слово, которое всё равно не влезает в ширину экрана, уменьшается дальше (не меньше 20) и остаётся в одну строку | 600 |
| `koreanHero` для текста с пробелами | выражение / предложение-вопрос | 36 → 32 → 28 по длине | 500 |
| `koreanSentence` | пример, предложение | 28 | 500 |
| `koreanOption` | корейские варианты ответа, разбор | 26; введённый ответ — 28 | 500 |
| `translation` | перевод | 26 | Inter SemiBold |
| `transcription` | транскрипция | 15 | Inter Regular |
| `instruction` | что сделать | 19 | Inter SemiBold |

- Межстрочный интервал: слова — 1,3×, предложения — 1,4×; обрезаний в скриншотах нет.
- Размер слова по длине — чистая функция `src/ui/koreanSize.ts` с тестами.
- Системное масштабирование шрифта **не отключено**; у главного слова только верхний предел `maxFontSizeMultiplier={1.6}`, чтобы 56 sp при 200 % не выходили за экран.

## 2. Шрифт

- Интерфейс — Inter (встроен). В Inter нет хангыля, а при подстановке терялось начертание.
- Поэтому у корейского текста свой шрифт — `koreanFont`:
  - **Android:** системный `sans-serif`, то есть Noto Sans CJK KR;
  - **iOS:** Apple SD Gothic Neo;
  - **веб:** Noto Sans KR, если установлен, затем системный корейский.
- Noto Sans KR **не встраивал:** это +5–10 МБ к APK, а на Android это тот же Noto Sans CJK.

## 3. Раскладка

- **Кнопка озвучки — 48 dp, под словом.** Порядок: слово → транскрипция → озвучка.
- **Задание закреплено вверху (отступ 24 dp), а не по центру.** Слово не прыгает, когда меняется поле ответа или открывается клавиатура. Меньше пустоты между шапкой и словом.
- **Предложения переносятся по словам**, а не посреди слова (`keepWords`, в вебе `word-break: keep-all`).
- **Подсказка в пустом корейском поле — 18 sp**, введённый текст — 28 sp. Иначе на экране 360 dp подсказка обрезалась.
- **Изменённые экраны:**
  - занятие (`study.tsx`) — все этапы: знакомство, узнавание, вспоминание, карточки, аудирование, диктант;
  - упражнения по грамматике (`grammar-drill.tsx`);
  - прослушивание трудных слов (`listen.tsx`);
  - каркас `StudyShell`.

## 6. Отклонения

- **Очень длинные слова — по ширине экрана, ниже 36 sp.** По решению владельца: 국제연합안전보장이사회 (11 слогов) при 36 sp не помещалось в 358 dp и переносилось между слогами. Теперь размер подгоняется под ширину экрана с учётом системного масштаба: 31 sp на 390 dp, 28 sp на 360 dp, одна строка (проверяется в каждом прогоне). Нижний предел — 20 sp; длиннее этого слово переносится. Ширина берётся от окна, а не измеряется: контейнеры слова сжимаются по содержимому, и измерение уменьшало бы слово шаг за шагом.
- **Веб: перезапуск страницы при занятой базе.** При быстрой перезагрузке страницы база ещё занята прошлой страницей. Теперь веб-версия один раз перезагружает страницу сама, не больше трёх раз подряд (`src/db/busy.ts`), а не показывает «Ошибка». На Android это не используется.
