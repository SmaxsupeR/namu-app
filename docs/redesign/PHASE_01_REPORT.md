# Namu UX v2 — Фаза 1: фундамент

Ветка: `redesign/ux-v2`. Это фундамент редизайна (шаги 1–2 раздела «Delivery» в UX.md): дизайн-токены, типографика, иконки, общие компоненты и навигация. Экраны «Сегодня», «Мои слова», «Прогресс», занятие и формы пока сохраняют свою раскладку и уже получают новую палитру, шрифт и иконки; их переработка — следующие фазы.

Учебная логика не менялась: `src/core`, `src/db`, FSRS, миграции, резервные копии, озвучка, словарь и офлайн-работа не затронуты.

## 1. Подготовка

- Локальных изменений не было.
- Ветка `redesign/ux-v2` была создана от `main` и **отставала на 15 коммитов** от рабочей версии приложения (`feature/tts-integration`): аудирование, лаборатория рукописного ввода, веб-версия, новый импорт, подборки, проверка ответов без «мой ответ тоже верный». Эти коммиты влиты в ветку редизайна (`0a31cd5`), чтобы редизайн шёл по актуальному приложению. В `main` ничего не сливалось.
- Исходное состояние: `npm test` — 458 пройдено, 1 пропущен; `npm run typecheck` — без ошибок. В первом прогоне один тест упал один раз и больше не воспроизводился (11 повторных прогонов чистые) — см. «Обнаруженные проблемы».

### Инвентаризация (до изменений)

- **Вкладки (5):** Главная, Словари, Справочник (`translate`), Практика, Прогресс.
- **Экраны стека:** занятие (`study`), свободная практика (`free`), прослушивание трудных слов (`listen`), слово (`word/[id]`), словарь (`dictionary/[id]`), редактирование словаря, добавление слова (`entry`), импорт, подборка (`dict-sample`), грамматика (`grammar/[id]`, `grammar-drill`), спряжение, настройки, лицензии, лаборатория рукописного ввода (`ink-lab`).
- **Тема:** 16 цветовых токенов, отступы, радиусы; шкалы шрифтов и размеров элементов не было.
- **Компоненты:** 13 в `ui/components.tsx` (`Btn`, `Card`, `Chip`, `Field`, `Screen`, `Empty`, `Bar` и др.).
- **Иконки:** MaterialCommunityIcons, около 75 разных, вперемешку заливка и контур.
- **Где жили функции без дублей:** направления обучения и способ ответа для плановых занятий были **только** на вкладке «Практика»; справочник (словарь, грамматика, спряжение) — только на вкладке «Справочник».

### 2.1. Дизайн-токены (`src/ui/theme.ts`)

- Цвета из DESIGN.md для светлой и тёмной темы. Добавлены семантические цвета обратной связи (success, danger, warn, info и их «мягкие» фоны), `divider`, `scrim`, `ripple`. **Все пары цветов текста проверены на WCAG AA:** минимальный контраст 5,0 : 1 при требовании 4,5 : 1.
- Шкала шрифтов: заголовок экрана 28 sp, раздел 20 sp, основной текст 16, второстепенный 14, подписи 13, кнопки 16, корейское слово в списке 20, корейское слово в задании 40.
- Отступы 4/8/12/16/24/32; радиусы 8/12/16 (без «пилюль», кроме чипов и переключателей); размеры: касание 48 dp, строка списка 56 dp.
- **Старые имена токенов сохранены** (`bg`, `primarySoft`, `textDim`…), поэтому новая палитра применилась ко всем экранам без правки каждого.

### 2.2. Типографика

- **Inter** (SIL OFL 1.1, лицензия — `assets/fonts/Inter-LICENSE.txt`), четыре начертания, урезаны до латиницы, кириллицы и знаков: 84–86 КБ каждое, 340 КБ вместо 1,7 МБ. Загружаются при старте из самого приложения, без сети.
- **`ui/Text`** заменил стандартный `Text` во всех 29 файлах. Он выбирает начертание Inter по жирности (Android выбирает начертание по имени шрифта, а не по `fontWeight`), по умолчанию берёт цвет текста темы и принимает вариант шкалы (`variant="title"` и т. п.). Системное масштабирование шрифта работает.
- **Хангыль** отображается системным корейским шрифтом — на Android это Noto Sans CJK KR (см. «Отклонения»).

### 2.3. Иконки

Feather из уже установленного `@expo/vector-icons` во всём приложении; MaterialCommunityIcons больше нигде не используется. Около 75 иконок заменены по единой таблице соответствий.

### 2.4. Компоненты

Переработаны на месте, с прежними именами и параметрами, чтобы экраны не ломались:

- `Btn` / `Button` — основная, тихая залитая, текстовая и деструктивная кнопки, все не ниже 48 dp.
- `IconBtn` / `IconButton` — 48×48 dp, обязательная подпись для TalkBack, состояние «недоступно».
- `Card` — тонкая граница, радиус 16; предназначен для отдельных блоков, а не для каждой строки.
- `Chip` — выбранный показан мягкой заливкой и рамкой, а не сплошным цветом.
- `Field` — Inter, подпись берётся из `label` или `placeholder`.
- `Section` — подпись группы без капслока.
- `Empty` / `EmptyState`, `Bar` / `ProgressBar`, `Fab`.

Новые:

### 2.5. Навигация

**Четыре вкладки:** Сегодня · Мои слова · Изучать · Прогресс. Подписи видны всегда.

```
Сегодня (/)            Мои слова (/dictionaries)        Изучать (/explore)                       Прогресс (/progress)
├─ Начать занятие      ├─ словари → /dictionary/[id]    ├─ Найти слово → /reference?section=words&focus=1
├─ Грамматика к        │   ├─ учить, добавить,          ├─ Тренировка
│  повторению          │   │  импорт, экспорт           │   ├─ Свободная практика → /free
├─ Недавние словари    ├─ Создать словарь               │   ├─ Карточки → /free?method=self_grade
├─ Краткий прогресс    └─ Подборка из словаря           │   ├─ Аудирование → /free?prompt=audio
└─ ⚙ → /settings                                        │   ├─ Диктант → /free?prompt=dictation
                                                        │   └─ Трудные слова → /free?source=hard
                                                        ├─ Справочник
                                                        │   ├─ Корейский словарь → /reference?section=words
                                                        │   ├─ Грамматика → /reference?section=grammar
                                                        │   └─ Спряжение → /reference?section=conjugate
                                                        └─ Эксперименты (только Android)
                                                            └─ Рукописный ввод → /ink-lab
```

- **Справочник** открывается из «Изучать» как экран с кнопкой «Назад» сразу на нужном разделе; разделы переключаются `SegmentedControl`.
- **Бывшие вкладки сохранили адреса:** `/translate` и `/practice` — теперь обычные экраны вне вкладок. Скрыть их как вкладки (`href: null`) оказалось нельзя: навигатор вкладок перенаправляет такой адрес на первую вкладку.
- **Направления обучения и способ ответа** для плановых занятий перенесены с вкладки «Практика» в «Настройки → Обучение» (`SegmentedControl`). Значения и их хранение прежние.
- **Во время занятия нижней навигации нет:** занятие, свободная практика, грамматические упражнения и лаборатория — экраны стека вне вкладок (проверено: при старте занятия вкладок на экране нет).
- **Новые параметры маршрутов:**
  - `/free?method=` — для строки «Карточки»;
  - `/reference?section=&focus=` — нужный раздел справочника и сразу открытая клавиатура.
- **`/design`** — страница-витрина токенов и компонентов для согласования. Из приложения на неё ссылок нет.

**Проверка критериев приёмки UX.md:**

| Критерий | Результат |
|---|---|
| Ежедневное занятие с «Сегодня» в одно нажатие | да |
| Аудирование за три нажатия с готовыми настройками | два: «Изучать» → «Аудирование» → «Начать» |
| Поиск по словарю за два нажатия | да: «Изучать» → поле поиска, клавиатура сразу открыта |

## 6. Обнаруженные проблемы

1. **Скрытая вкладка недоступна по адресу.** `href: null` в навигаторе вкладок перенаправляет на первую вкладку. Исправлено переносом экранов вне вкладок (`38e59d3`).
2. **Массовая замена иконок задела не только иконки.** Она изменила имя маршрута `translate` → `globe` и строку `'cards'` в `src/db/repo.ts`. Оба случая найдены проверкой типов и проходом по маршрутам, изменения в `src/db` откачены до коммита. Других непредусмотренных замен нет: diff по экранам проверен.
3. **`Alert.alert` в вебе ничего не показывает.** Подтверждения удаления и сообщения в веб-версии молча не работают — это проблема и до редизайна. `ConfirmationDialog` её решает, но экраны на него ещё не переведены (фаза 3).
4. **Веб: при очень быстрой перезагрузке страницы база может быть ещё занята** прошлой вкладкой (`createSyncAccessHandle`). Видел только при автоматических перезагрузках подряд, к редизайну отношения не имеет.
5. **Нестабильный тест:** один сбой в первом прогоне, дальше 11 чистых прогонов. Подробности первого сбоя не сохранились; скорее всего, это тест со временем, упавший под нагрузкой сразу после слияния. Стоит повторять `npm test` перед слиянием.
6. **Экраны со старой раскладкой.** «Сегодня», «Мои слова», «Прогресс», занятие и формы получили новую палитру, шрифт и иконки, но раскладка у них прежняя: карточки, длинные пояснения. Это ожидаемо для фазы 1.

## 7. Отклонения от DESIGN.md и UX.md

| Решение | Почему |
|---|---|
| **Feather вместо Lucide** | Lucide — ответвление Feather с той же сеткой 24 px и линией 2 px. Feather уже установлен в `@expo/vector-icons`, а Lucide потребовал бы `lucide-react-native` и нативную `react-native-svg`. AGENTS.md просит не добавлять зависимости без необходимости. Если понадобятся иконки, которых в Feather нет, можно перейти на Lucide отдельным шагом: имена в основном совпадают |
| **Noto Sans KR не встроен** | На Android системный корейский шрифт — Noto Sans CJK KR, то есть тот же Noto, и он уже есть на каждом телефоне. Встроенный Noto Sans KR добавил бы несколько мегабайт к APK и к веб-загрузке без видимой разницы. Хангыль читаем: проверено на 40 sp и 20 sp |
| **Корейское слово в задании — 40 sp** | Это середина диапазона 36–48 sp из DESIGN.md |
| **Страница `/design`** | В документах её нет. Нужна для согласования компонентов, из приложения на неё ссылок нет. Можно удалить после согласования |
| **Свободная практика: значения по умолчанию не изменены** | UX.md предлагает 20 слов, все словари, оба направления, клавиатуру, 3 попытки. Сейчас по умолчанию 20 слов, все словари, **одно** направление (한 → перевод), клавиатура, 3 попытки. Это фаза 4 («Study and free practice»), здесь не менялось |
| **Экран «Сегодня» без `ScreenHeader`** | Сохранено приветствие, кнопка настроек на месте. Экран переделывается в фазе 3 |

## 8. Рекомендации для следующей фазы

1. **Сначала проверить фундамент на ваших телефонах:**
   - шрифт Inter и хангыль рядом с ним;
   - кнопка «Назад» на Android;
   - TalkBack на вкладках и строках «Изучать»;
   - масштаб шрифта 130–200 %;
   - тёмная тема.
2. **Фаза 3 — «Сегодня», «Мои слова», добавление слова:**
   - «Сегодня»: одно главное действие, убрать дублирующиеся цифры, подсказки веба свернуть в одну строку;
   - «Мои слова»: `ListGroup` + `ListRow` вместо карточек, действия словаря — в меню;
   - словарь: `SearchField` + `FilterSheet` + `WordRow`;
   - добавление слова: два обязательных поля, остальное под «Дополнительно»;
   - все `Alert.alert`-подтверждения перевести на `ConfirmationDialog`, чтобы они работали и в вебе.
3. **Фаза 4:**
   - перевести `study.tsx` и `grammar-drill.tsx` на `StudyShell`;
   - выровнять значения свободной практики по UX.md и запоминать последний выбор.
4. **После согласования внешнего вида** удалить `/design` или закрыть её флагом разработки.
